# shamira-te-quiero 💛

Un regalo interactivo, estático y mobile-first para el Día de las Flores Amarillas.

## Publicar en GitHub Pages

1. Sube esta carpeta a la rama `main` del repositorio.
2. En GitHub abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main`, carpeta `/(root)` y guarda.

La web quedará en `https://farixromero.github.io/shamira-te-quiero/`.

### Personalización rápida

Edita el arreglo `messages` en `script.js` y el texto final en `index.html` para hacerlo todavía más de ustedes dos.
